# ZloUriShim

`ZloUriShim.exe` records and replays Battlefield 3 launches generated by the
ZLO Battlelog replica. Current Battlelog builds launch BF3 with an HTTP GET to
ZClient's local endpoint:

```text
http://localhost:5080/ZLO/run?game=Z.BF3&cmd=...
```

The tool can discover those requests in Chromium browser caches and issue the
same request without opening the browser. It also retains support for capturing
and forwarding the older `zlo://` protocol.

Build and install:

```powershell
go build -o .\build\ZloUriShim.exe .\cmd\zlourishim
.\build\ZloUriShim.exe install
```

If no `zlo://` handler is currently registered, specify ZClient explicitly:

```powershell
.\build\ZloUriShim.exe install --target 'C:\path\to\ZClient.exe'
```

After launching singleplayer and multiplayer once from Battlelog, discover and
record the local launch URLs:

```powershell
.\build\ZloUriShim.exe discover
```

Each URL is appended as one JSON object to:

```text
%LOCALAPPDATA%\ZloUriShim\captures.jsonl
```

Treat the log as sensitive because multiplayer launches may contain
session-related values.

Replay the most recently captured launch without opening the browser:

```powershell
.\build\ZloUriShim.exe replay --last
```

Launch BF3 singleplayer directly using the known Battlelog command template:

```powershell
.\build\ZloUriShim.exe launch --mode sp
```

Launch multiplayer using the selected Battlelog game ID:

```powershell
.\build\ZloUriShim.exe launch --mode mp --game-id 14609
```

Or replay a particular captured localhost URL:

```powershell
.\build\ZloUriShim.exe launch --url 'http://localhost:5080/ZLO/run?...'
```

Inspect or remove the override:

```powershell
.\build\ZloUriShim.exe status
.\build\ZloUriShim.exe uninstall
```

The `install` command is only needed for legacy `zlo://` capture. It refuses to
overwrite a pre-existing per-user registration. Uninstall checks the ownership
marker before deleting the override. The capture configuration and log are
intentionally retained after uninstall.
